# SDK Build Notes

The SDK is built as a .xcframework and must be built from the command line.


## Step 1: Open the Terminal and navigate to the project folder.

Note: The project uses Xcode 13 and the command line tools must be installed and setup.


## Step 2: Type 'sh BuildFramework.sh' to build the framework.

The built releasable framework will be located at:

Build/Framework Products/TuneURL.xcframework
